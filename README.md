# PEN GROUP Assessment Test

A responsive Next.js implementation of the supplied VCAD homepage, course listing, and course-detail designs.

## Run locally

From this directory, install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). To test the production build, run `npm run build` followed by `npm run start`.

## Approach and How I've finished it.

- First of all, I've went through the design, then noticed the typography, color theme and elements.
- Then downloaded most of the elements and images and checked the related css desgins in figma
- As the design is in 1440\*979px format I need to check it from 1440p resolution so that it matches the proper design making it pixel perfect.
- The tricky thing was there's a carousel slider and the nav menu is bit off centered so tried to position these.
- Also noticed that the overall layout uses a white line as a background which made the design a proper grid type system.
- I thought I've to finish all 3 pages but I've done 2 of them. Courses details one is mostly generated by AI so I'll not take any credit for it.
- AI Tools I've used: claude code, codex

## A design decision I made

The designs did not define loading or empty states for the course listing. I added a loading skeleton that follows the course-grid layout and an empty state for a missing course list, avoiding a blank or collapsed page while data is loading or unavailable.
